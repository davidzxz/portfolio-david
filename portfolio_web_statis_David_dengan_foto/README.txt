## Cara menjalankan
### VS Code + Live Server
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Buka `index.html`.
4. Jalankan dengan Live Server.

### XAMPP / localhost
1. Salin folder `portfolio_web_statis` ke `C:/xampp/htdocs/`.
2. Jalankan Apache di XAMPP.
3. Buka `http://localhost/portfolio_web_statis/`.
